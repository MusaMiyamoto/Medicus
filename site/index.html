Medicus OS: en trygg arbeidsstasjon for helsepersonell Medicus OS: a secure workstation for health personnel

Logg inn med helsepersonellkort, åpne pasientjournalen, skriv notat med journalassistenten, og la maskinen passe på resten: låst skjerm når kortet tas ut, bare godkjente nettsteder, og revisjonslogg for alt som skjer. Log in with a health-personnel card, open the patient record, write a note with the journal assistant, and let the machine take care of the rest: the screen locks when the card is removed, only approved websites open, and everything is written to an audit log.

Medicus is not a medical device and must not be used for real patients. It is made for machines owned by a health institution or the government.

Prøv det selvTry it yourself

Medicus OS starter fra en ISO-fil i en virtuell maskin. Det tar rundt ti minutter. Medicus OS runs from an ISO file in a virtual machine. It takes about ten minutes.

  1. Last ned medicus-os-amd64.hybrid.iso (omtrent 1,9 GB) fra utgivelsene på GitHub. Download medicus-os-amd64.hybrid.iso (about 1.9 GB) from the releases on GitHub.
  2. Lag en ny virtuell maskin: type Linux, Debian 64-bit, minst 4 GB minne, 2 prosessorer og 20 GB disk. Velg ISO-filen som startdisk. Create a new virtual machine: type Linux, Debian 64-bit, at least 4 GB of memory, 2 processors and a 20 GB disk. Choose the ISO file as the boot disk.
  3. Start maskinen og velg Start Medicus. Etter oppstart ser du innloggingen. Start the machine and choose Start Medicus. After booting you see the login screen.
  4. Velg et demokort nedenfor i listen nederst, trykk Sett inn kort, og skriv PIN 1234. Knappen «English» nederst til høyre bytter språk. Pick a demo card below from the list at the bottom, press Insert card, and type PIN 1234. The «English» button at the bottom right switches the language.
